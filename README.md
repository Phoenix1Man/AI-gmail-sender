# AI-gmail-sender
Smart email generation, personalization &amp; scheduling tool powered by AI


📬 AI Gmail Sender is a smart SaaS tool that helps professionals generate, personalize, and schedule email campaigns using AI. Built for speed, automation, and results.

🔍 Features
✨ AI-powered email generation using FLAN-T5

💌 Dynamic personalization with {{name}}, {{company}}, and more

📅 Smart scheduling (send now or later)

📊 Template management and contact segmentation

🧠 Subject line generation with OpenAI-compatible transformer model

🔒 User login system with Flask + MySQL

📎 File attachments (PDFs, CVs, etc.)

🌐 Uses Gmail API for real authenticated sending

🛠️ Technologies Used
Frontend	Backend	AI/NLP	Other Tools
HTML + Bootstrap	Flask	HuggingFace Transformers	Gmail API
JS (Ajax)	Flask-Login	FLAN-T5 (Google)	MySQL (via flask-mysqldb)
Jinja2	REST API	Tokenizer + T5 model	Google OAuth
🧪 Current Status
✅ Beta version complete — UI + Core features live
🔄 Working on multi-user Gmail auth & tracking dashboard
📬 Currently sending real Gmail emails via secure OAuth
